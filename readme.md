# 🚀 Faraós Moto Clube

Progressive Web App ainda em desenvolvimento criada para gerenciamento de passeios e eventos do motoclube FaraósMC, além de permitir a eleição de membros e outras funcionalidades a ser trabalhadas futuramente.  


---

## 📋 Funcionalidades

- Criar eventos
- Confirmar presença
- Comentar em eventos
- Listar próximos passeios
- Votar em membros para ocupação de cargos no motoclube

---

## 🛠 Tecnologias

Este projeto foi desenvolvido utilizando:

- **Backend:** ASP.NET Core  
- **Frontend:** React  
- **Banco de dados:** Sqlserver 
- **ORM:** Entity Framework Core
